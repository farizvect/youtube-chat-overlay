YouTube Chat Overlay

Real-time YouTube chat for OBS Browser Source. One command to install.

1

Install

Copy-paste the command for your OS into the terminal. Installs everything — Bun, dependencies, and opens the setup wizard.

$ curl -fsSL https://raw.githubusercontent.com/farizvect/youtube-chat-overlay/refs/heads/main/install.sh | bash

PS> irm https://raw.githubusercontent.com/farizvect/youtube-chat-overlay/refs/heads/main/install.ps1 | iex

The wizard will ask for font, colors, background style, and more. Your config is saved and can be changed anytime.

2

Start the server

Every time you go live, run this from the install directory:

$ cd ~/youtube-chat-overlay && bash start.sh

PS> cd ~/youtube-chat-overlay; .\start.ps1

You'll pick a config preset, then enter the YouTube live video ID or channel handle. The server starts on http://localhost:6969.

3

Add to OBS

Add a Browser Source in OBS pointing to the overlay server.

Source Type
Browser
URL
http://localhost:6969
Width
1280
Height
720
💡 Pro tip: Right-click the Browser Source in OBS and select Interact to test it without going live.
4

Customize anytime

Run the setup wizard to change fonts, colors, manage GIFs, or switch config presets — even while streaming. Changes apply instantly via hot-reload.

$ cd ~/youtube-chat-overlay && bun setup.js
🎨 4 font choices (Roboto, Inter, Poppins, etc.)
🖼️ GIF triggers — word → custom GIF
📐 3 positions — left, center, right
💬 Inline chat — compact mode
⭐ Super Chat — glow + extended time
🎭 Multi-config — presets per stream type
